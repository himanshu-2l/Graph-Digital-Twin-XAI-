# Editable Figure Source Files (Figure 2 - Cognitive GDT Framework)

This directory contains all editable formats for **Figure 2: Cognitive Graph Digital Twin Framework**.

## Files Included

1. **`gdt_framework_matplotlib.svg`** — **SVG Vector Graphic**
   - *How to Edit:* Drag & drop into [Draw.io](https://app.diagrams.net), PowerPoint, or Adobe Illustrator. In Draw.io/PowerPoint, click **"Ungroup"** or **"Convert to Shape"** to edit individual text labels, boxes, and arrows.

2. **`cognitive_gdt_framework.drawio`** — **Draw.io Diagram Source**
   - *How to Edit:* Open directly in [Draw.io](https://app.diagrams.net) or the Draw.io desktop app.

3. **`gdt_framework_matplotlib.pdf`** — **Vector PDF File**
   - *How to Edit:* Vector PDF editable in Adobe Illustrator, Inkscape, or Acrobat Pro. Ready for Overleaf LaTeX inclusion.

4. **`gdt_figure_matplotlib.py`** — **Python Matplotlib Script**
   - *How to Edit:* Run `python gdt_figure_matplotlib.py` to programmatically update node coordinates, labels, colors, and styling.

5. **`gdt_figure_tikz.tex`** — **LaTeX TikZ Source Code**
   - *How to Edit:* Paste directly into Overleaf or any LaTeX compiler to edit using TikZ syntax.

6. **`gdt_framework_matplotlib.png`** — **High-Resolution PNG Preview (300 DPI)**
