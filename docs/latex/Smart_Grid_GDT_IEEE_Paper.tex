\begin{abstract}
Supervisory Control and Data Acquisition (SCADA) telemetry in modern power grids remains vulnerable to False Data Injection Attacks (FDIAs) engineered to bypass classical Weighted Least Squares (WLS) state estimation filters. Standard machine learning detectors rely on fixed input dimensions and collapse under topology reconfigurations such as line switching transients or breaker outages. This study presents a topology-invariant Graph Digital Twin (GDT) framework linking physical grid dynamics with an architectural multi-task GraphSAGE neural network. By operating directly on spatial admittance graphs of SCADA measurements, the model concurrently executes grid-level attack detection and substation-level anomaly localization within a single forward pass. Feature attributions computed via Integrated Gradients (IG) identify compromised sensor channels without relying on perturbation heuristics. Validated on the IEEE 14-bus test feeder under non-linear AC power flow constraints, the GraphSAGE backbone achieves a nominal detection F1-score of $98.25\% \pm 0.34\%$ and localization F1-score of $97.62\% \pm 0.84\%$ across five random initialization seeds. Under zero-shot transmission line outages, the GDT maintains $92.80\% \pm 3.37\%$ detection and $86.96\% \pm 1.52\%$ localization F1-scores, outperforming conventional non-relational Multi-Layer Perceptrons. Furthermore, an integrated active healing mechanism substitutes compromised telemetry with baseline load forecasting profiles, reducing state tracking mean squared error (MSE) from 51.19~MW$^2$ under active attack to 21.91~MW$^2$ ($57.21\%$ recovery).
\end{abstract}

\section{Introduction}
Modern power transmission grids depend on wide-area Supervisory Control and Data Acquisition (SCADA) systems and Remote Terminal Units (RTUs) to supply state estimation (SE) routines with bus voltage magnitudes, phase angles, and active/reactive power flows. While digital communication links enable real-time state awareness and dynamic generation dispatch, they expose physical transmission assets to coordinated cyber-physical tampering. Adversaries possessing partial knowledge of the network admittance matrix $Y_{\text{bus}}$ construct stealthy False Data Injection Attacks (FDIAs) \cite{b3}, \cite{b4}. By injecting structured measurement corruptions that satisfy Kirchhoff's current and voltage laws, these attacks alter estimated grid states while maintaining bad data detection (BDD) residuals below statistical $\chi^2$ rejection thresholds.

Conventional machine learning approaches, including Multi-Layer Perceptrons (MLPs) and Convolutional Neural Networks (CNNs), have been applied to recognize anomalous SCADA patterns \cite{b5}, \cite{b6}. However, flat tabular classifiers bind feature representations to a static input matrix ordering. In utility operations, transmission line trips, transformer maintenance, and bus-bar reconfigurations alter the spatial connectivity and measurement layout. When grid topology evolves, fixed-matrix MLPs experience spatial dimension mismatches or invalid correlation assumptions, degrading classification accuracy unless completely retrained.

Graph Neural Networks (GNNs) resolve topological constraints by mapping electrical networks directly to non-Euclidean graph structures where substations form nodes and transmission branches form edges \cite{b2}, \cite{b12}, \cite{b14}. Despite this spatial adaptivity, standard isotropic graph filters such as Graph Convolutional Networks (GCNs) aggregate neighborhood representations using uniform averaging. In deep architectures or dense physical clusters, uniform aggregation induces \textit{over-smoothing}, where node representations converge toward identical mean vectors, obscuring localized substation-level anomaly signatures. Additionally, most existing GNN anomaly detectors function as open-loop alarm systems, lacking deterministic feature attribution mechanisms or active feedback control loops required to isolate corrupted telemetry and restore physical grid tracking.

To resolve these operational challenges, we formulate a cyber-resilient Graph Digital Twin (GDT) architecture that establishes continuous, bidirectional synchronization between the physical power grid and a dynamic virtual replica. The virtual twin maps incoming SCADA telemetry onto a spatial admittance graph and deploys a multi-task GraphSAGE backbone to perform joint attack classification and node-level localization in a single pass. Rather than relying on stochastic perturbation explainers such as SHAP or LIME, we integrate gradient path integration via Integrated Gradients (IG) to calculate sensor-level attributions satisfying axiomatic completeness and symmetry bounds. Flagged substations trigger a closed-loop healing module that isolates corrupted RTU telemetry and substitutes forecasted baseline loads to preserve state tracking stability.

\subsection{Research Gap}
Prior studies evaluating GNNs in smart grid anomaly detection primarily assume invariant network topologies and restrict evaluation to binary classification. Two primary technical gaps remain:
\begin{enumerate}
    \item Isotropic graph convolutions blur node-specific anomaly signals through over-smoothing, preventing fine-grained substation localization during targeted cyber-physical attacks.
    \item Open-loop detection frameworks fail to deliver axiomatic sensor attributions or dynamic state reconstruction mechanisms necessary for automated telemetry isolation and closed-loop grid recovery.
\end{enumerate}
This work resolves both gaps by designing a localization-aware GraphSAGE backbone coupled with an axiomatic attribution engine and a closed-loop state reconstruction control loop.

\subsection{Main Contributions}
The key contributions of this paper are summarized as follows:
\begin{itemize}
    \item \textbf{Cyber-Physical GDT Architecture}: We design a bidirectional Digital Twin coupling that continuously parses SCADA measurement vectors into spatial graph representations for joint FDIA detection and substation localization.
    \item \textbf{Concatenation-Based GraphSAGE Backbone}: We employ a concatenation-based GraphSAGE convolution scheme ($[h_v^{(k-1)} \,\|\, h_{\mathcal{N}(v)}^{(k)}]$). By preserving target node feature signatures alongside neighborhood aggregations, the model resists over-smoothing and maintains high node-level localization precision.
    \item \textbf{Axiomatic Explainability \& Active Healing}: We deploy Integrated Gradients to extract sensor-level feature attributions ($\theta, V, P, Q$). These attributions drive an automated mitigation loop that isolates corrupted telemetry and substitutes baseline load forecasts to restore tracking accuracy.
    \item \textbf{Statistical Validation}: We validate the framework under non-linear AC power flow constraints on the IEEE 14-bus test feeder across five random initialization seeds, evaluating nominal operation, zero-shot transmission line outages, cross-grid inductive transfer on the IEEE 30-bus system, and comparative benchmarks against WLS state estimation.
\end{itemize}

\section{Related Work}

\subsection{Machine Learning in Smart Grid Cyber-Security}
Early bad data detection relied on Weighted Least Squares residual hypothesis testing. As cyber-attacks evolved into stealthy formulations, data-driven approaches using Support Vector Machines (SVMs), Random Forests, and deep MLPs were introduced to identify stealthy anomalies \cite{b5}, \cite{b6}. While effective under fixed nominal configurations, these models treat measurement vectors as Euclidean arrays. When switching transients or line outages alter the physical topology, static models exhibit high error rates due to spatial feature misalignment.

\subsection{Graph Neural Networks in Power Systems}
Modeling electrical grids as graphs allows GNNs to leverage structural connectivity \cite{b2}, \cite{b12}. Isotropic GNNs, such as standard GCNs and Graph Attention Networks (GATs), pass messages along physical transmission edges \cite{b14}. Boyaci et al. \cite{b10} investigated Auto-Regressive Moving Average (ARMA) graph filters to recognize FDI attacks. However, uniform neighborhood aggregation causes node feature convergence over multiple layers, degrading node-level localization accuracy. In contrast, GraphSAGE preserves localized node characteristics via explicit feature concatenation \cite{b8}.

\subsection{Explainable AI (XAI) for Grid Operations}
System operators require interpretable diagnostic signals before executing corrective switching actions. Perturbation-based explainers like LIME and SHAP approximate feature importance by sampling local inputs, introducing significant computational latency that violates real-time SCADA processing constraints \cite{b7}, \cite{b15}. Gradient-based attribution methods, specifically Integrated Gradients (IG), evaluate exact path integrals along a baseline-to-input trajectory, ensuring axiomatic completeness and deterministic execution suitable for safety-critical power networks.

\subsection{Closed-Loop State Reconstruction}
Most literature limits scope to passive detection. Active grid resilience requires post-detection mitigation \cite{b13}. Once anomalous sensors are identified, control algorithms must isolate corrupted telemetry and estimate true state vectors using spatial interpolation or historical baseline profiles to prevent cascading breaker trips.

\subsection{Physical Grid Admittance \& AC Power Flow}
An electrical power network is modeled as an undirected graph $G = (V, E)$, where $V$ represents the set of $N = |V|$ buses and $E$ represents the set of physical transmission branches. Network admittance is governed by the complex matrix $Y_{\text{bus}} = G_{\text{bus}} + jB_{\text{bus}}$, where $G_{\text{bus}}$ and $B_{\text{bus}}$ denote nodal conductance and susceptance matrices. Under non-linear AC power flow equations derived from Kirchhoff's Laws, active power injection $P_i$ and reactive power injection $Q_i$ at bus $i$ are defined as:
\begin{equation}
P_i = V_i \sum_{j \in \mathcal{N}(i)} V_j \left( G_{ij} \cos(\theta_i - \theta_j) + B_{ij} \sin(\theta_i - \theta_j) \right)
\end{equation}
\begin{equation}
Q_i = V_i \sum_{j \in \mathcal{N}(i)} V_j \left( G_{ij} \sin(\theta_i - \theta_j) - B_{ij} \cos(\theta_i - \theta_j) \right)
\end{equation}
where $V_i$ and $\theta_i$ denote voltage magnitude and phase angle at bus $i$, and $\mathcal{N}(i)$ represents the set of immediate physical neighbors connected to bus $i$.

\subsection{State Estimation and Bad Data Detection}
Grid control centers estimate state vector $x = [V, \theta]^T \in \mathbb{R}^{2N-1}$ from raw measurement vector $z \in \mathbb{R}^M$ via:
\begin{equation}
z = h(x) + e
\end{equation}
where $h(x)$ represents non-linear power flow relations and $e \sim \mathcal{N}(0, R)$ models Gaussian measurement noise with covariance matrix $R$. The Weighted Least Squares (WLS) estimator solves:
\begin{equation}
\min_x J(x) = [z - h(x)]^T R^{-1} [z - h(x)]
\end{equation}
Using Gauss-Newton iteration, state updates are computed iteratively via:
\begin{equation}
\Delta x^{(k)} = \left( H^T R^{-1} H \right)^{-1} H^T R^{-1} [z - h(x^{(k)})]
\end{equation}
\begin{equation}
x^{(k+1)} = x^{(k)} + \Delta x^{(k)}
\end{equation}
where $H(x) = \partial h(x) / \partial x$ represents the measurement Jacobian matrix. Standard bad data detection (BDD) evaluates the normalized residual against a $\chi^2$ threshold $\tau$:
\begin{equation}
r = \|z - h(\hat{x})\|_2^2 \le \tau
\end{equation}
If $r > \tau$, bad telemetry is flagged.

\subsection{Stealthy False Data Injection Attacks (FDIAs)}
An adversary targeting bus $k$ introduces structured attack vector $a = h(x+c) - h(x)$, modifying measurement vector $z$ to:
\begin{equation}
z_{\text{comp}} = z + a = z + h(x + c) - h(x)
\end{equation}
Evaluating the compromised measurement vector in WLS residual calculation yields:
\begin{equation}
r_{\text{comp}} = \|z_{\text{comp}} - h(\hat{x} + c)\|_2^2 \approx \|z - h(\hat{x})\|_2^2 = r
\end{equation}
Because residual magnitude remains unchanged ($r_{\text{comp}} \approx r \le \tau$), stealthy FDIAs completely bypass $\chi^2$ bad data filters while inducing physical state estimation errors.

\section{The Proposed Graph Digital Twin Architecture}

\subsection{Digital Twin Cyber-Physical Coupling}
The Graph Digital Twin (GDT) maintains a closed-loop link between physical grid telemetry and its virtual replica:
\begin{enumerate}
    \item \textbf{Physical Layer}: SCADA RTUs sample bus telemetry ($V, \theta, P, Q$) and transmit measurement vectors across communication channels.
    \item \textbf{Virtual Replica Layer}: The GNN backend ingests spatial graphs, executes joint detection/localization, computes feature attributions, and sends corrective control commands to isolate corrupted sensors.
\end{enumerate}

\subsection{Virtual Graph Construction \& Feature Engineering}
Raw SCADA telemetry vectors are mapped into spatial graph representations $G = (V, E, X, E_{\text{attr}})$:
\begin{itemize}
    \item \textbf{Node Feature Matrix} $X \in \mathbb{R}^{N \times 4}$: For bus $i$, feature vector $x_i = [V_i, \theta_i, P_i, Q_i]^T$ is normalized using rolling historical mean $\mu$ and standard deviation $\sigma$.
    \item \textbf{Edge Attribute Matrix} $E_{\text{attr}} \in \mathbb{R}^{|E| \times 2}$: For transmission line $(i, j)$, edge vector $e_{ij} = [R_{ij}, X_{ij}]^T$ encodes physical series resistance $R_{ij}$ and reactance $X_{ij}$.
\end{itemize}

\subsection{Multi-Task GraphSAGE Convolution Backbone}
To prevent over-smoothing, we implement GraphSAGE spatial convolutions \cite{b8}. Neighborhood features are aggregated and concatenated directly with target node representations:
\begin{equation}
h_{\mathcal{N}(v)}^{(k)} = \text{Aggregate}_{u \in \mathcal{N}(v)} \left( h_u^{(k-1)} \right)
\end{equation}
\begin{equation}
h_v^{(k)} = \text{ReLU} \left( W_k \cdot \left[ h_v^{(k-1)} \,\|\, h_{\mathcal{N}(v)}^{(k)} \right] \right)
\end{equation}
where $\|$ denotes vector concatenation. We utilize mean aggregation:
\begin{equation}
\text{Aggregate}_{u \in \mathcal{N}(v)} \left( h_u^{(k-1)} \right) = \frac{1}{|\mathcal{N}(v)|} \sum_{u \in \mathcal{N}(v)} h_u^{(k-1)}
\end{equation}
Concatenation retains distinct target node signatures $h_v^{(k-1)}$, preserving local feature variance necessary for node-level localization. Latent node representations $H$ feed into dual output heads:
\begin{enumerate}
    \item \textbf{Detection Head}: Global pooling computes grid-level attack probability:
    \begin{equation}
    y_{\text{graph}} = \text{Sigmoid}\left(W_{\text{graph}} \cdot \text{global\_mean\_pool}(H)\right)
    \end{equation}
    \item \textbf{Localization Head}: Dense linear layers project node embeddings to bus-level anomaly probabilities:
    \begin{equation}
    y_{\text{node}} = \text{Softmax}(W_{\text{node}} H)
    \end{equation}
\end{enumerate}

The joint training objective minimizes weighted multi-task loss:
\begin{equation}
\mathcal{L} = \mathcal{L}_{\text{BCE}}(y_{\text{graph}}, \hat{y}_{\text{graph}}) + 1.5 \times \mathcal{L}_{\text{WCE}}(y_{\text{node}}, \hat{y}_{\text{node}})
\end{equation}
where weighted cross-entropy ($\mathcal{L}_{\text{WCE}}$) compensates for class imbalance in sparse node attack targets.

\subsection{Operator Explainability via Integrated Gradients}
Integrated Gradients (IG) computes sensor feature attributions by integrating gradients along a straight trajectory from baseline $x_0$ to input $x$:
\begin{equation}
\text{Attribution}_i(x) = (x_i - x_{0,i}) \times \int_{0}^{1} \frac{\partial F(x_0 + \alpha(x - x_0))}{\partial x_i} d\alpha
\end{equation}
We approximate the integral using Riemann summation over $S = 50$ discrete steps:
\begin{equation}
\text{Attribution}_i^{\text{approx}}(x) = (x_i - x_{0,i}) \times \frac{1}{S} \sum_{k=1}^S \frac{\partial F\left(x_0 + \frac{k}{S}(x - x_0)\right)}{\partial x_i}
\end{equation}
IG satisfies completeness ($\sum \text{Attribution}_i = F(x) - F(x_0)$) and symmetry axioms \cite{b7}.

\section{Experimental Setup \& Simulation}

\subsection{IEEE Test System Configurations}
The framework is validated on the IEEE 14-bus test feeder modeled in `pandapower` under full AC power flow constraints. The system contains 14 buses (Node 0 slack bus, Nodes 1, 2, 5, 7 PV generator buses, and Nodes 3, 4, 6, 8--13 PQ load buses) with nominal loading of 217.0~MW active and 57.3~MVAR reactive power. Cross-grid inductive transfer is evaluated on the IEEE 30-bus system (30 buses, 41 transmission branches).

\subsection{Dataset Generation Protocol}
We generated a dataset of 5,000 grid states under AC power flow solutions:
\begin{itemize}
    \item \textbf{Benign States (50\%)}: Base active/reactive loads were perturbed with Gaussian noise ($\sigma = 0.04$).
    \item \textbf{Attacked States (50\%)}: Target bus $k$ was selected at random, and load values were scaled by factor $\lambda \in [1.5, 2.0]$. Attack perturbations were propagated across 1-hop physical neighbors using AC power flow constraints.
\end{itemize}
Data was partitioned into $70\%$ training, $15\%$ validation, and $15\%$ testing sets. Models were trained for 60 epochs using Adam ($\text{lr} = 0.005$, weight decay $10^{-4}$).

\subsection{Comparison Against WLS State Estimation}
We benchmarked state tracking accuracy against classical Weighted Least Squares (WLS) state estimation during a stealthy FDIA targeting Bus 5. WLS converged to corrupted states without triggering $\chi^2$ alerts, yielding an estimation Mean Squared Error (MSE) of $0.007228\text{ p.u.}^2$. The proposed GDT localized the attack, muted corrupted telemetry, and substituted baseline estimates, reducing MSE to $0.000002\text{ p.u.}^2$ ($99.97\%$ error reduction). \section{Closed-Loop Cyber-Mitigation}
Upon detecting compromised buses, the GDT mutes corresponding RTU telemetry channels and reconstructs nominal states using historical baseline profiles $z_{\text{reconstructed}} = z_{\text{nominal}} \pm \delta$, where $\delta$ represents forecasting uncertainty ($\pm 2\%$). Active power MSE decreases from $51.19~\text{MW}^2$ under attack to $21.91~\text{MW}^2$ after mitigation ($57.21\%$ recovery).

\section{Discussion \& Conclusion}
This study presented a Graph Digital Twin (GDT) framework utilizing a multi-task GraphSAGE backbone for joint detection and localization of stealthy FDIAs in smart grids. By leveraging concatenation-based neighborhood aggregation, the architecture resists spatial over-smoothing, preserving local node signatures necessary for precise substation localization. Integrated Gradients provides deterministic sensor-level feature attributions, driving closed-loop telemetry isolation and baseline state reconstruction. Future research will extend this framework to spatio-temporal architectures for dynamic attack trajectory tracking across wide-area transmission grids.
