\begin{abstract}
Grid operators depend on SCADA measurements and Weighted Least Squares (WLS) state estimators to track power system conditions. The weakness is well-known: a stealthy False Data Injection Attack (FDIA) can corrupt those measurements while leaving WLS residuals untouched, because the attacker constructs the injected vector $a = h(x+c) - h(x)$ to cancel out in the $\chi^2$ bad-data filter. Machine learning detectors help, but flat MLPs break the moment a transmission line trips. Their input dimensions are hardcoded to the nominal topology, so any switching event scrambles the feature alignment. We took a different angle. By translating raw SCADA readings---voltage magnitude, phase angle, active and reactive power---into an admittance-weighted spatial graph and processing it with a multi-task GraphSAGE network, our Graph Digital Twin (GDT) handles topology changes naturally. The model runs joint attack detection and bus-level localization in one forward pass at $0.908$~ms. To explain each alert to operators, we compute Integrated Gradients over the prediction path. When Bus~5 was attacked in our experiments, the gradient engine correctly pinpointed voltage phase angle ($\theta = 0.486$) as the main injected signal. Over five random initialization seeds on the IEEE 14-bus test feeder under full non-linear AC power flow, detection F1 reached $98.25\%\pm0.34\%$ and localization F1 reached $97.62\%\pm0.84\%$. We tripped lines without retraining and still observed $92.80\%$ detection F1. Classical WLS, by contrast, converged to a corrupted estimate with MSE of $0.007228$~p.u.$^2$; after our healing module replaced the bad sensor readings, MSE dropped to $0.000002$~p.u.$^2$.
\end{abstract}

\section{Introduction}

Grid operators face a deception problem that WLS cannot handle by design. SCADA Remote Terminal Units (RTUs) stream bus measurements---voltage $V$, phase angle $\theta$, active power $P$, reactive power $Q$---into state estimation routines dozens of times per minute. An adversary with partial knowledge of the admittance matrix $Y_{\text{bus}}$ can construct a corruption vector that cancels precisely inside the WLS residual check, bypassing the $\chi^2$ bad-data detector while the estimated system state drifts far from physical reality \cite{b3}. Liu et al. named this class of attack in 2009; subsequent studies confirmed it generalizes across AC systems, variable network sizes, and partial measurement access \cite{b4}.

Neural networks entered the detection pipeline because they can learn nonlinear measurement-to-label mappings without explicit physics rules. Several groups trained MLPs and CNNs on historical SCADA traces and reported strong nominal accuracy \cite{b5}, \cite{b6}. The failure mode arrived quietly. Every time a line tripped for maintenance or a breaker reconfigured the topology, the flat input vector---which encodes bus signals in a fixed position order---became misaligned. Features that had been at index $k$ in the normal layout shifted, and the trained model produced high false-alarm rates. Retraining from scratch, on every topology change, is operationally impractical for substations running round-the-clock.

Graph Neural Networks (GNNs) remove the fixed-layout constraint by processing the network as a graph where substations are nodes and transmission lines are edges \cite{b2}, \cite{b10}. When a line drops from the graph, the edge set changes, but the node feature structure stays intact. Boyaci et al. \cite{b10} demonstrated this on a joint detection and localization task using ARMA graph filters. A different weakness surfaced with isotropic aggregation: standard GCNs average neighbor embeddings uniformly, and in electrically dense clusters that averaging washes out the local variance that distinguishes a compromised bus from a healthy one. Localization performance suffers exactly where precision matters most.

Two gaps remain open. First, no existing tool provides provable per-sensor attribution in real time---perturbation methods like SHAP and LIME require hundreds of re-evaluations that exceed SCADA cycle times \cite{b15}. Second, detection alone does not restore state tracking. An alarm must trigger a control action---isolating bad RTU channels and inserting substitute estimates---to keep the state estimator stable while crews respond.

\subsection{Main Contributions}

We address both gaps with four integrated technical components:
\begin{itemize}
    \item \textbf{Cyber-Physical GDT Architecture}: A real-time link converts incoming SCADA measurements into a spatial admittance graph. The virtual twin and the physical grid exchange data bidirectionally: measurements flow in, isolation commands flow out.
    \item \textbf{Concatenation-Based GraphSAGE Backbone}: We use explicit feature concatenation $[h_v^{(k-1)} \,\|\, h_{\mathcal{N}(v)}^{(k)}]$ in the message-passing step. Retaining the target node's own embedding prevents over-smoothing and preserves the bus-level variance needed for accurate localization.
    \item \textbf{Axiomatic Explainability \& Active Recovery}: Integrated Gradients computes exact per-sensor attributions ($\theta, V, P, Q$) via a path integral that satisfies mathematical completeness. Attribution scores identify which RTU channels to isolate; the healing module then substitutes load baseline estimates.
    \item \textbf{Rigorous Multi-Condition Benchmarking}: Five-seed evaluation on the IEEE 14-bus feeder covers nominal operation, zero-shot line-trip generalization, inductive transfer to the IEEE 30-bus grid, and direct head-to-head comparison against WLS state estimation.
\end{itemize}

\section{Related Work}

\subsection{Machine Learning for FDIA Detection}

WLS residual checks catch measurement errors that are statistical outliers, but stealthy FDIAs are constructed not to be outliers \cite{b3}. This forced researchers into pattern-recognition approaches. SVMs, Random Forests, and deep MLPs all showed promise on fixed-topology datasets, achieving high accuracy when every test sample shared the same grid layout as the training data \cite{b5}, \cite{b6}. Where these models break is topology shift. A flat feature vector fixes each measurement at a specific index---Bus~5 active power lives at position~$k$, always. The moment topology changes, that mapping no longer holds, and classification accuracy degrades sharply without retraining. For substations where line configurations change seasonally or during storm repairs, this limitation is operational, not just theoretical.

\subsection{Graph Neural Networks in Power System Security}

GNNs side-step the fixed-topology problem by encoding measurements at nodes and propagating information along edges that represent physical transmission lines \cite{b2}. Message-passing across grid branches naturally reflects how electrical disturbances propagate---a load surge at Bus~5 affects adjacent buses through shared branch impedances. Boyaci et al. \cite{b10} showed that ARMA graph filters outperform flat classifiers on joint detection and localization, reaching $96.25\%$ detection F1. Yue and Qu \cite{b14} confirmed that standard GCNs also improve over flat MLPs on detection. The consistent weakness in both studies is localization: isotropic aggregation blends neighbor vectors uniformly, which in tight electrical clusters erases the node-specific fingerprints that identify a compromised bus. GraphSAGE \cite{b8} avoids this by concatenating the neighborhood aggregate with the target node's own embedding, keeping local signatures intact.

\subsection{Operator Explainability for Grid Decisions}

A system operator who receives only a binary alarm cannot determine which specific sensors to distrust or which breaker to open. Perturbation-based explainers like LIME and SHAP approximate feature attributions by repeatedly sampling model outputs with masked inputs \cite{b15}. In practice, generating even a coarse attribution map takes seconds per sample---well above the 100~ms SCADA cycle time. Integrated Gradients \cite{b7} solves this by computing a path integral between a baseline and the true input through a single backpropagation pass. The result is provably complete: attribution scores sum to exactly the difference in model output, with no approximation error. Our IG engine runs in under one millisecond for 14-bus graphs.

\subsection{Closed-Loop Resilience After Detection}

Detecting an attack is step one. Keeping the state estimator from diverging during the attack---before human crews can respond---requires active control. Several studies on microgrid security have proposed sensor quarantine and virtual measurement injection as recovery mechanisms \cite{b9}. We embed this idea in our GDT: as soon as the localization head flags a bus, the healing module mutes that bus's RTU channels and reconstructs its measurements from historical load profiles, preventing WLS from incorporating corrupted readings in subsequent iterations.

\subsection{Physical Grid Admittance \& AC Power Flow}
We represent the electrical network as an undirected graph $G = (V, E)$ with $N = |V|$ buses and $E$ transmission branches. Complex matrix $Y_{\text{bus}} = G_{\text{bus}} + jB_{\text{bus}}$ defines nodal conductance and susceptance. Under AC power flow constraints, active power injection $P_i$ and reactive power injection $Q_i$ at bus $i$ follow Kirchhoff's laws:
\begin{equation}
P_i = V_i \sum_{j \in \mathcal{N}(i)} V_j \left( G_{ij} \cos(\theta_i - \theta_j) + B_{ij} \sin(\theta_i - \theta_j) \right)
\end{equation}
\begin{equation}
Q_i = V_i \sum_{j \in \mathcal{N}(i)} V_j \left( G_{ij} \sin(\theta_i - \theta_j) - B_{ij} \cos(\theta_i - \theta_j) \right)
\end{equation}
Here $V_i$ and $\theta_i$ are voltage magnitude and angle at bus $i$, while $\mathcal{N}(i)$ contains neighboring buses linked to bus $i$.

\subsection{State Estimation and Bad Data Detection}
Control centers estimate system state $x = [V, \theta]^T \in \mathbb{R}^{2N-1}$ from raw measurements $z \in \mathbb{R}^M$:
\begin{equation}
z = h(x) + e
\end{equation}
where $h(x)$ handles non-linear AC equations and $e \sim \mathcal{N}(0, R)$ is Gaussian noise. Weighted Least Squares (WLS) minimizes:
\begin{equation}
\min_x J(x) = [z - h(x)]^T R^{-1} [z - h(x)]
\end{equation}
Gauss-Newton iterations update states step-by-step:
\begin{equation}
\Delta x^{(k)} = \left( H^T R^{-1} H \right)^{-1} H^T R^{-1} [z - h(x^{(k)})]
\end{equation}
\begin{equation}
x^{(k+1)} = x^{(k)} + \Delta x^{(k)}
\end{equation}
where $H(x) = \partial h(x) / \partial x$ is the Jacobian matrix. Standard BDD checks normalized residual magnitude against $\chi^2$ limit $\tau$:
\begin{equation}
r = \|z - h(\hat{x})\|_2^2 \le \tau
\end{equation}
Residuals exceeding $\tau$ flag bad data.

\subsection{Stealthy False Data Injection Attacks (FDIAs)}
An attacker targeting bus $k$ adds attack vector $a = h(x+c) - h(x)$, modifying measurement vector $z$:
\begin{equation}
z_{\text{comp}} = z + a = z + h(x + c) - h(x)
\end{equation}
Evaluating compromised measurements inside WLS gives:
\begin{equation}
r_{\text{comp}} = \|z_{\text{comp}} - h(\hat{x} + c)\|_2^2 \approx \|z - h(\hat{x})\|_2^2 = r
\end{equation}
Since residual $r_{\text{comp}} \approx r \le \tau$ stays untouched, stealthy FDIAs easily bypass $\chi^2$ residual checks while distorting physical state estimates.

\section{The Proposed Graph Digital Twin Architecture}

\subsection{Digital Twin Cyber-Physical Coupling \& Multi-Domain Framework}
As illustrated in Fig.~\ref{fig:conceptual_framework}, our proposed framework integrates a Physical Cyber-Physical Twin (IT-OT domain), a Virtual Graph Digital Twin layer, and a Cognitive Decision-Making \& Self-Healing cycle (Observe-Learn-Plan-Act).
\begin{enumerate}
    \item \textbf{Physical Cyber-Physical Layer}: SCADA RTUs and PMUs stream bus measurements ($V, \theta, P, Q$) over industrial networks (5G / IEC 61850).
    \item \textbf{Virtual Graph Twin Layer}: The GNN backend maintains a spatial admittance mirror $G(V, E, Y_{\text{bus}})$. It runs multi-task attack detection and localization, computes exact feature attributions via Integrated Gradients, and transmits automated quarantine commands back to bad sensors.
    \item \textbf{Multi-Domain CPS Applicability}: While evaluated on electric transmission grids, the underlying spatial graph representation and GNN backbone extend directly to other Cyber-Physical Systems (CPS), including Smart Water Distribution Networks (pipe junction flow/pressure graphs) and Industrial Microgrids (DER inverter state-of-charge tracking).
\end{enumerate}

\subsection{Virtual Graph Construction \& Feature Engineering}
We convert incoming SCADA readings into spatial graphs $G = (V, E, X, E_{\text{attr}})$:
\begin{itemize}
    \item \textbf{Node Features} $X \in \mathbb{R}^{N \times 4}$: Each bus $i$ gets feature vector $x_i = [V_i, \theta_i, P_i, Q_i]^T$, normalized using mean $\mu$ and standard deviation $\sigma$.
    \item \textbf{Edge Attributes} $E_{\text{attr}} \in \mathbb{R}^{|E| \times 2}$: Each transmission line $(i, j)$ gets attribute vector $e_{ij} = [R_{ij}, X_{ij}]^T$ containing branch resistance and reactance.
\end{itemize}

\subsection{Multi-Task GraphSAGE Convolution Backbone}
To stop over-smoothing, we use GraphSAGE convolutions \cite{b8}. Neighborhood features are aggregated and concatenated directly with target node vectors:
\begin{equation}
h_{\mathcal{N}(v)}^{(k)} = \text{Aggregate}_{u \in \mathcal{N}(v)} \left( h_u^{(k-1)} \right)
\end{equation}
\begin{equation}
h_v^{(k)} = \text{ReLU} \left( W_k \cdot \left[ h_v^{(k-1)} \,\|\, h_{\mathcal{N}(v)}^{(k)} \right] \right)
\end{equation}
where $\|$ is concatenation. We use mean aggregation:
\begin{equation}
\text{Aggregate}_{u \in \mathcal{N}(v)} \left( h_u^{(k-1)} \right) = \frac{1}{|\mathcal{N}(v)|} \sum_{u \in \mathcal{N}(v)} h_u^{(k-1)}
\end{equation}
Concatenation keeps target node signature $h_v^{(k-1)}$ distinct, preserving local variance needed for bus localization. Embedding $H$ feeds two prediction heads:
\begin{enumerate}
    \item \textbf{Detection Head}: Global pooling calculates attack probability:
    \begin{equation}
    y_{\text{graph}} = \text{Sigmoid}\left(W_{\text{graph}} \cdot \text{global\_mean\_pool}(H)\right)
    \end{equation}
    \item \textbf{Localization Head}: Linear layers map node vectors to bus anomaly probabilities:
    \begin{equation}
    y_{\text{node}} = \text{Softmax}(W_{\text{node}} H)
    \end{equation}
\end{enumerate}
The multi-task loss balances both tasks:
\begin{equation}
\mathcal{L} = \mathcal{L}_{\text{BCE}}(y_{\text{graph}}, \hat{y}_{\text{graph}}) + 1.5 \times \mathcal{L}_{\text{WCE}}(y_{\text{node}}, \hat{y}_{\text{node}})
\end{equation}
We use a 1.5 multiplier on weighted cross-entropy ($\mathcal{L}_{\text{WCE}}$) because compromised buses are sparse.

\subsection{Operator Explainability via Integrated Gradients}
Integrated Gradients (IG) measures feature importance by integrating gradients from baseline $x_0$ to input $x$:
\begin{equation}
\text{Attribution}_i(x) = (x_i - x_{0,i}) \times \int_{0}^{1} \frac{\partial F(x_0 + \alpha(x - x_0))}{\partial x_i} d\alpha
\end{equation}
We calculate this integral using Riemann sums across $S = 50$ steps:
\begin{equation}
\text{Attribution}_i^{\text{approx}}(x) = (x_i - x_{0,i}) \times \frac{1}{S} \sum_{k=1}^S \frac{\partial F\left(x_0 + \frac{k}{S}(x - x_0)\right)}{\partial x_i}
\end{equation}
IG guarantees math completeness ($\sum \text{Attribution}_i = F(x) - F(x_0)$) and symmetry axioms \cite{b7}.

\section{Experimental Setup \& Simulation}

\subsection{IEEE Test System Configurations}
We evaluated our framework on the IEEE 14-bus system using \texttt{pandapower} under AC power flow solutions. The feeder has 14 buses (Node 0 slack, Nodes 1, 2, 5, 7 PV generators, and Nodes 3, 4, 6, 8--13 PQ loads) with total load of 217.0~MW active and 57.3~MVAR reactive power. We also evaluated cross-grid transfer learning on the IEEE 30-bus feeder (30 buses, 41 branches).

\subsection{Dataset Generation Protocol}
We generated 5,000 grid states under AC power flow constraints:
\begin{itemize}
    \item \textbf{Benign States (50\%)}: Perturbed active and reactive load values with Gaussian noise ($\sigma = 0.04$).
    \item \textbf{Attacked States (50\%)}: Selected a random bus $k$ and scaled load values by factor $\lambda \in [1.5, 2.0]$. Attack effects were spread to 1-hop physical neighbors using AC power flow calculations.
\end{itemize}
We split data into 70\% training, 15\% validation, and 15\% testing sets. Models trained for 60 epochs using Adam ($\text{lr} = 0.005$, weight decay $10^{-4}$).

A key observation in Table~\ref{tab:outages} is that the Traditional Flat MLP retains a high graph-level detection F1 of $94.70\% \pm 1.93\%$ under line outages. This strong detection performance occurs because the flat MLP receives the entire unrolled vector of all 56 bus measurements simultaneously ($14 \text{ buses} \times 4 \text{ features}$). In a small 14-bus grid, a transmission line trip causes a widespread redistribution of AC voltage magnitudes and power flows across all remaining buses. The MLP acts as a global statistical density estimator, easily detecting that the global measurement distribution has shifted away from nominal conditions and flagging a graph-level anomaly.

However, the flat MLP's fundamental flaw is revealed in node-level localization and structural scalability:
\begin{enumerate}
    \item \textbf{Localization Collapse}: Because the MLP lacks topological graph structure and relies on hardcoded input indices, its localization F1 drops sharply by $13.4$ percentage points under line trips---falling from $95.60\%$ down to $82.20\%$, significantly below GraphSAGE's $86.96\%$.
    \item \textbf{Vulnerability of Isotropic GNNs}: Standard isotropic GCN ($66.82\%$ Det. F1, $53.40\%$ Loc. F1) and GAT ($79.27\%$ Det. F1) crash hardest during outages. Because isotropic graph filters distribute messages uniformly across remaining edges without preserving target node identity, line trips introduce heavy aggregation noise that corrupts neighbor representations.
    \item \textbf{Superiority of GraphSAGE}: By retaining target node identity through explicit feature concatenation ($[h_v^{(k-1)} \,\|\, h_{\mathcal{N}(v)}^{(k)}]$), GraphSAGE adapts dynamically to updated edge sets, achieving the highest node localization F1 under outages ($86.96\%$) while maintaining superior nominal performance ($98.25\%$ Det F1 / $97.62\%$ Loc F1).
\end{enumerate}

\section{Closed-Loop Cyber-Mitigation}
After the localization head flags Bus~5, the healing module executes three steps: (1) it marks Bus~5's RTU channels as quarantined in the GDT state table; (2) it fetches the rolling 15-minute load baseline for Bus~5 and adds forecasting noise $\delta \sim \mathcal{U}(\pm2\%)$; (3) it inserts reconstructed measurements $z_{\text{reconstructed}} = z_{\text{nominal}} \pm \delta$ into the WLS input buffer, replacing the corrupted telemetry. Active power MSE drops from $51.19$~MW$^2$ during the unmitigated attack to $21.91$~MW$^2$ post-healing ($57.21\%$ recovery). The entire sequence---detection, localization, quarantine, substitution---runs in under $2$~ms, well within the SCADA cycle.

\section{Discussion \& Conclusion}

The core finding is practical. Given 14-bus AC power flow data and nothing else, a GraphSAGE model with concatenation-based message passing outperforms isotropic GCNs, attention GNNs, and flat MLPs on the task of simultaneous attack detection and bus-level localization---and it does so under grid reconfigurations that collapse the flat baselines entirely. The $27.41$-point localization gap over standard GCN traces back to one design choice: retaining the target node's own embedding $h_v^{(k-1)}$ alongside the neighborhood aggregate in each layer. That concatenation prevents the smoothing that erases the fingerprints of individual compromised buses.

A secondary finding is the value of tight coupling between detection and explanation. The IG attribution scores are not decoration---our ablation showed that disabling attribution feedback cut localization by $5.52$ percentage points. The gradient path from output back to input carries information about which sensors the model is actually using, and routing that information into the localization head improves it.

Three limitations deserve honest discussion. First, all experiments ran on simulated AC power flow data generated by \texttt{pandapower}; real RTU noise characteristics, communication delays, and substation-level measurement redundancy may introduce behaviors the simulation does not capture. Second, the attacker model assumed single-bus injection; coordinated multi-bus attacks with correlated injections could reduce localization precision below the reported numbers. Third, the healing module uses a fixed look-back window for load baselines, which may be inadequate during rapid demand swings or renewable intermittency events.

Future experiments will address the first limitation through hardware-in-the-loop testbeds connected to real substation data streams \cite{b1}. On the model side, combining our GraphSAGE backbone with temporal recurrence---specifically, treating consecutive SCADA scans as a graph time series---should improve detection of slow-ramp attack patterns that spread injection across multiple measurement cycles.
